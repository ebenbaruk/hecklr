# Milestone M3: production loop and red-team suite usable from the UI

Status, 2026-10-24: **PASSED, with open P2/P3 caveats.** Each gate row below has evidence. Some
of it was re-run for this report on `main` at `b4813a4`, for $0: a red-team run, the miner,
approving a scenario in the UI, running it, labeling, and a browser check. The rest is the
evidence recorded in the workstream PRs (#64, #65, #61) and in the M3 red-team pass. No P0 or P1
issue is open. The open caveats: on a checkout install the UI needs an undocumented npm build
(#106, P2). Safety graders that call a judge cannot be labeled in the UI (#87, P2). Some UI
colours fail WCAG AA contrast (#110, P3). The miner leaves cluster labels blank with `fake/`
models (#109, P3).

Gate M3 (spec, "Waves"): "production loop and red-team suite usable from the UI". Workstreams:
WS13 miner (PR #64, ADR 0013a), WS14 adversarial pack (PR #65, ADR 0014a), WS16 UI (PR #61,
ADR 0016a). The M3 red-team findings were fixed in PR #120. Spec IDs: US-03, US-08, US-09,
US-11.

## Re-run on `main`, 2026-10-24

This run was for this report. Tree `b4813a4`, Apple M1 Pro with 10 cores, load average 1.5-5.8.
Everything ran at $0: the rules brain, `fake/customer` and `fake/judge` models, and local Ollama
`hecklr-bench-qwen3-4b` for the miner's labels and proposals. The scratch project was a copy of
`examples/acme-maintenance` in a session scratch directory, outside the repository, with three
edits to its `hecklr.yaml`: the chat adapter URL on its own port (34205), `simulator:` and
`judge:` set to `fake/customer` and `fake/judge`, and one added suite for the US-08 step,
`mined: { scenarios: "scenarios/mined/*.yaml", trials: 3, channels: [chat] }`. The acme
example itself defines no `mined` suite.

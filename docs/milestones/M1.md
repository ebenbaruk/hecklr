## How to reproduce

From the repository root, on the PR #39 head:

```bash
uv sync --all-packages --all-extras
# Free tier: rules brain, scripted smoke suite, deterministic graders. No key, $0. Nightly in CI.
uv run python scripts/fault-matrix/fault_matrix.py --tier free
# Tier A: rules brain, the matrix suite (smoke + 18 judge-only twins), gpt-6-luna judges. About $0.15.
uv run --env-file .env python scripts/fault-matrix/fault_matrix.py --tier a --budget-usd 0.5
# Tier B: LLM agent, guided customers and judges, all on gpt-6-luna, matrix-live suite x 3 trials.
# About $0.35 per run, 8 runs, about $2.8. It runs 15-18 min per run on a loaded laptop.
uv run --env-file .env python scripts/fault-matrix/fault_matrix.py --tier b --budget-usd 3.2
```

Each tier writes `matrix.json` and `matrix.md` to `--out` (default `.hecklr/fault-matrix/<tier>`,
git-ignored). It also writes the copied project that was tested (`project/`), the result store
(`store/runs/<run id>/`, with `report.html` per run), and the gate reports per variant
(`reports/<variant>/report.{html,json,md}`, `junit.xml`). It writes the agent, run, report and
gate logs to `logs/`. The script exits 0 when every row meets SC8, 1 when one does not, and 3 when
the matrix could not measure. The baseline run is the cost pilot: the script prints the projected
cost of the tier and stops before spending more if the cost would exceed `--budget-usd`.

**Caught** means two things. `hecklr gate` must exit 1 (a suite regression). Every expected
grader's own paired comparison (same α = 0.05, δ = 3 pts, cluster bootstrap and sign-flip test)
must also give a regression. The A/A row passes when the gate exits neither 1 (regression) nor 3
(harness error).

## Red team

Every probe ran against the reference agent or a purpose-built bad agent (`rt_agent.py`: crash,
hang, HTTP 500, garbage, 20 MB replies, XSS payloads).

| Probe | Result |
| --- | --- |
| Bad `hecklr.yaml` and bad flags | Held: exit 78 / 2 with a message, no traceback |
| Missing API key | Held: exit 78 before any trial (but see #19 for model-free suites) |
| Agent crashes mid-run, returns 500, returns garbage | Held: agent errors per trial, run completes |
| Agent hangs | Held: per-turn timeouts, run completes |
| Huge responses (20 MB per reply) | **#34 (P2)**: no reply size cap; a 33-trial run made a 2.9 GB store and a 3.0 GB HTML report |
| Every trial an agent error, no baseline | **#33 (P2)**: exits 0 and passes the gate; it can become the stored baseline |
| Concurrent runs on one store | Held: both runs complete and stay separate |
| Interrupted run (SIGINT), then gate and compare | Held: recorded as cancelled; `gate` exits 3. **#35 (P3)**: prints an asyncio `CancelledError` traceback |
| Statistical edge cases: n = 1, all pass, all fail | Held: n = 1 is inconclusive, all-pass A/A passes, all-fail vs all-fail passes |
| XSS in transcripts (`<script>` payloads from the agent) | Held: escaped in HTML and Markdown reports |
| Cost estimate for scripted suites | **#36 (P3)**: charges for model calls that never happen; `--budget-usd 0` is refused |
| Judge cites a mistyped event id | **#37 (P3)**: becomes an error grade without a retry (~1% of luna judge calls) |
| Guided refund and invoice scenarios | **#29 (P1)**: the hecklr-sim consistency guard rejects valid turns; every such scenario is a harness error |
| Matrix run during a provider outage | Found and **fixed in PR #39**: an outage passed for a caught fault (`check_health`) |
| CI colour codes | Found and **fixed in PR #39**: `FORCE_COLOR=1` hid the run id from the runner |

None of #29, #33-#37 is in WS-m1's owned paths, so they are filed rather than fixed here. #28
(a LiveKit timing test that flakes under xdist) also failed one CI run of PR #39.

## Known gaps

- **Tier B F1-F6** (#45, #29): the gate is open.
- The free tier's A/A cannot detect false alarms, because it is deterministic. Tier A's A/A
  re-samples only the judges.
- Margins: F2, F4 and F5 sit at the smallest attainable p with 6 flipped scenarios.
- Spec deviations, proposed in ADR 0020a: F1's overlay states the opposite rule rather than
  deleting it, and the fault table's `tool_called` is read as the Tool grader family.
- The `handoff_appropriate` rubric was clarified: "late" means after routine business, not
  elapsed time. This changes its version hash, and no persisted calibration in the repository
  references the old hash.
- Process incident: during the earlier Tier B runs, a broad `pkill` pattern used to stop stale
  matrix agents also killed WS12b's `acme-email` agent and invalidated that workstream's
  `email-fault-matrix.sh` run. The runner stops only the processes it started (by handle). For
  manual cleanup, stop processes by PID, never by pattern.

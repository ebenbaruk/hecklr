# v1.0 gate: success criteria SC1-SC10

Status, 2026-10-24, `main` at `b4813a4`: **NOT PASSED.** Six of the ten success criteria are
met: SC2, SC6 and SC9 fully, and SC1, SC4 and SC5 with caveats. SC8 is met with caveats. Three
are **not met**:

- **SC3:** measured only on a 10-core machine; the spec asks for 8 cores.
- **SC7:** the judge κ values are against AI-drafted labels, not human ones.
- **SC10:** the docs site is not live, the 90-second video does not exist, and the benchmark rows
  are preliminary and unpublished.

No P0 or P1 issue is open. The M2 gate is still open (SC3 on 8 cores; SC4 over WebRTC, #59).
M1 and M3 are passed ([M1](M1.md), [M2](M2.md), [M3](M3.md)).

The spec's rule (Goals): "v1.0 is done when every criterion below is met and proven by an
automated test or a published artifact, not by a claim in the README." Nothing is published yet:
the repository is private and nothing is deployed ([LAUNCH](LAUNCH.md)). "CI" below means the
local merge gate, `scripts/ci-local.sh`. GitHub Actions is off on the private repository
(ADR 0022a).

## Known gaps

- **Gates that are still open.** M2 is open: SC3 on 8 cores, and SC4 over WebRTC (#59).
- **Evidence that predates the statistics fix.** PR #120 changed how Δ is computed for
  all-or-nothing suites (#98). Every M1/M2 interval printed before it was computed the old way.
  The verdicts are not affected, because they rest on the permutation p-value. On this report's
  tree, a deterministic agent on a small suite now gets INCONCLUSIVE (exit 2) where it used to
  get NO CHANGE.
- **Fault coverage that is not automated.** F10, the voice CLI matrix (F7-F10 through
  `hecklr run`) and the live tiers are not in any automated job. Only F1-F6 (free tier) and
  F7-F9 (scripted) run on every merge.
- **Wired but unused statistics.** Flaky-scenario flagging and the judge drift warning exist in
  `hecklr-stats` but no command uses them (#102). `--adaptive` never applies its group-sequential
  looks (#103).
- **The local gate.** It runs on one macOS laptop shared with other work, so Linux-only failures
  can slip through (ADR 0022a). Timing steps fail under host load (#121, #90, #94).
- **Launch checklist** ([LAUNCH](LAUNCH.md)). There are 0 open `good first issue` issues (#111).
  The README badges point at GitHub Actions workflows that are off. The Pipecat and LiveKit
  community examples and posts are not written.
- **Fixer demo.** The `hecklr fix` beat of the demo is not recorded. The command has been proven
  live once (session `01M5K3SFHE8PW4B9MN1TWKACZ5`, targeted +77.8 pts [+55.6, +94.4], guard
  0.0 pts [−10.3, +10.3]).
